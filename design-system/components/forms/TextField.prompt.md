Campo de texto con etiqueta visible siempre arriba, ayuda opcional y mensaje de error con ícono.
```jsx
<TextField id="tel" label="Tu WhatsApp" type="tel" inputMode="tel" autoComplete="tel" help="10 dígitos" />
<TextField id="nombre" label="Nombre" error="Escribe tu nombre." />
```
- Foco: borde y sombra azul. Error: borde y sombra roja + mensaje. Nunca uses el placeholder como etiqueta.
